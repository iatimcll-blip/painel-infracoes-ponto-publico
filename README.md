# Painel Infrações de Ponto

Painel visual (HTML estático) com as correções aplicadas e os indicadores do workbook **PAINEL INFRAÇÕES.xlsx** — Jarvis MCLL · alloha FIBRA.

Conteúdo:
- Correções e atualizações aplicadas ao workbook (bug de GOs ocultos, sincronização de ciclo, novas métricas, formatação visual).
- Indicadores do ciclo selecionado, infrações por GO e por GA, evolução por ciclo.
- Colaboradores agrupados por hierarquia (bloco por GA), com detalhamento dia a dia (data/hora) por colaborador.
- Log da última importação de dados (base de ponto + hierarquia).

Gerado a partir de dados reais da base de ponto — nomes de colaboradores e contagens de infrações são reais.
